Firmware sources for the ESP32-S3 controller live here.

- `esp-idf/main`: main application entry points and bootstrapping
- `esp-idf/components`: reusable firmware modules
- `esp-idf/partitions`: partition table definitions
- `esp-idf/host_tests`: host-simulated logic tests
- `esp-idf/qemu`: QEMU smoke-test assets
- `esp-idf/test_apps`: target-side test apps and fixtures
- `esp-idf/tools`: firmware helper scripts
- `tests`: hardware bench, end-to-end, and soak-test artifacts

Normative behavior, storage, OTA, and verification rules live under `../docs/specifications/`.
