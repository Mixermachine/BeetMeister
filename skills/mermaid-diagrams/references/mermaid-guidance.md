# Mermaid Guidance

## Repo-specific rules

- Use `<br>` for Mermaid line breaks inside labels.
- Do not use `\n` as a Mermaid label newline.
- Keep Mermaid labels short and move detailed explanation into surrounding prose when needed.
- When state changes, transitions, or lifecycle rules are documented, add a Mermaid state diagram as part of the documentation baseline.
